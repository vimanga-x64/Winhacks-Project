# FitTrack App

FitTrack is a wellness and recovery assistant that brings activity tracking, nutrition insights, and progress reporting into a single, user-friendly experience. It is designed for students, employees, and anyone who wants a clear, actionable view of their health data.

### Frontend: `identify_food` Integration

Use this endpoint when the user uploads a food image and the UI needs a short English dish description generated by AI.

#### Endpoint
```http
POST /identify-food
Content-Type: multipart/form-data
```

#### Request
- Form field name: `file`
- Accepted input: image file from `<input type="file" />`, drag-and-drop, or camera capture
- Backend URL in frontend: use `import.meta.env.VITE_API_URL || "http://localhost:8000"`

#### Response
```json
{
  "description": "breaded stuffed chicken with mashed potatoes"
}
```

#### Example frontend request
```ts
const API_BASE_URL = import.meta.env.VITE_API_URL || "http://localhost:8000";

export async function identifyFood(file: File): Promise<string> {
  const formData = new FormData();
  formData.append("file", file);

  const res = await fetch(`${API_BASE_URL}/identify-food`, {
    method: "POST",
    body: formData,
  });

  if (!res.ok) {
    const errorText = await res.text();
    throw new Error(errorText || "Failed to identify food");
  }

  const data = await res.json();
  return data.description;
}
```

#### Minimal React usage example
```tsx
const [foodDescription, setFoodDescription] = useState<string | null>(null);
const [foodLoading, setFoodLoading] = useState(false);
const [foodError, setFoodError] = useState<string | null>(null);

const handleFoodImageUpload = async (file: File) => {
  setFoodLoading(true);
  setFoodError(null);

  try {
    const description = await identifyFood(file);
    setFoodDescription(description);
  } catch (error) {
    setFoodError(error instanceof Error ? error.message : "Upload failed");
  } finally {
    setFoodLoading(false);
  }
};
```

#### Recommended UX flow
- User selects or captures an image.
- Frontend sends the raw file as `FormData`.
- Show loading state while backend processes the image.
- On success, display the returned `description`.
- Optionally prefill a food input field with that description so the user can edit it before calorie estimation.

#### Validation and errors
- If the uploaded file is not an image, backend returns `400`.
- If OpenAI processing fails or backend throws, frontend receives `500`.
- Do not manually set the `Content-Type` header for `FormData`; the browser will add the correct multipart boundary.

#### Recommended placement in this project
- Add the API helper near the existing backend calls in [src/FitnessApp.tsx](D:/Rustem/2_Education/7_Data_science/16_WinHack_2026/src/FitnessApp.tsx).
- Reuse the same `API_BASE_URL` pattern already used for `/estimate`, `/recommendation`, and `/recovery`.
- Best insertion point is before the user submits a manual food text entry, so image recognition can prefill the text field.
